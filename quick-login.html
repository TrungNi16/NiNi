📖 Hướng dẫn lấy JSON từ Ugphone:

  1. Đăng nhập Ugphone trên trình duyệt Chrome/Edge
  2. Nhấn F12 → chọn tab Application
  3. Menu trái: Local Storage → chọn domain Ugphone
  4. Copy toàn bộ JSON (dạng {"key":"value"})
  5. Dán vào ô bên dưới → Bấm Tạo Code
✅ Code của bạn:

📖 Hướng dẫn sử dụng code:

  1. Nhập code bạn nhận được vào ô bên dưới
  2. Nếu code có mật khẩu, nhập mật khẩu
  3. Bấm Đăng nhập
  4. Hệ thống tự động điền vào Local Storage
